# Postmortem: GPU Memory Exhaustion During Traffic Spike

## Summary
During a product launch, inference workers repeatedly crashed with out-of-memory errors and the model backend returned ERR-5003 to 18 percent of requests.

## Root cause
Continuous batching admitted too many long sequences; `max_num_seqs` had been raised without a load test, so the KV cache did not fit in accelerator memory.

## Action items
Restore the previous concurrency limit, add admission control based on prompt length, and load test before changing batching limits.
