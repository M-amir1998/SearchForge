# Postmortem: Expired TLS Certificate Caused API Outage

## Summary
For 47 minutes the public API was unreachable because the edge TLS certificate expired. Clients failed the TLS handshake.

## Root cause
Automatic certificate renewal had silently failed for three weeks after a DNS change broke the ACME challenge. The expiry alert was routed to a decommissioned channel.

## Action items
Route the certificate expiry alert to the paging system, add a renewal smoke test and document manual renewal.
