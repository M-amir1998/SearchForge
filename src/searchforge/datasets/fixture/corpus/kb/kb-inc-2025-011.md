# Postmortem: Search Served Stale Results

## Summary
For two days the knowledge-base search returned outdated answers: documents deleted or edited weeks earlier still appeared in results.

## Root cause
The serving alias still pointed to an old index version after a failed rebuild, and the query cache key did not include the index version, so cached results survived even after the alias was fixed.

## Action items
Make cache keys index-version aware, alert when the serving index is older than 24 hours, and add a stale-document regression query.
