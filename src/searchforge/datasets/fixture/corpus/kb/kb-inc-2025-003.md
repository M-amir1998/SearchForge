# Postmortem: Cache Stampede After Deploy

## Summary
A deploy flushed the shared cache. Thousands of requests missed the cache at the same moment and overloaded the database for 12 minutes, a classic thundering herd.

## Root cause
Cache keys included the release version, so every key changed at once.

## Action items
Add request coalescing so only one request recomputes a missing key, and warm the cache before shifting traffic.
